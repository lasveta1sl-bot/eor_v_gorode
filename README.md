# В городе

В ГОРОДЕ — РЕСУРС ДЛЯ ДЕМОНСТРАЦИИ

Быстрое открытие без интернета: дважды щёлкните «В_городе_без_интернета.html».
В одном файле находятся все используемые изображения, оформление и логика. Интернет и установка программ не нужны.

Режимы: знакомство; исходные карточки; картинка → слово; слово → значение.
Стрелки ← → меняют флеш-карты, пробел показывает или скрывает ответ. При переходе ответ снова скрыт.
Кнопка «Демонстрация» увеличивает поле показа и скрывает управление; Escape возвращает управление.
Активное ядро А и расширение Б переключаются отдельно.
Новые слова, для которых в источнике нет карточек, доступны в знакомстве и «слово → значение». В режиме исходных карточек и «картинка → слово» показываются оригинальные пары.

В папке «Версия_для_GitHub» находится статический сайт. Загрузите всё содержимое папки в отдельный репозиторий и выберите публикацию Pages из корня основной ветки. index.html — вход, offline.html — автономный файл для скачивания.
Учебник целиком и учебниковые аудиозаписи в опубликованный набор не включены.

Изображения исходных карточек, пиктограмм, плакатов и команд сохранены без изменений. Дополнительные фото взяты из предоставленных материалов 4_Miro; новые значки нарисованы в SVG. Связи схем и примеры основаны на языковой карте.
